# Python Data Cleaner

A simple Python automation script that cleans and organizes CSV files using **Pandas**.  
This project removes empty rows, trims column names, sorts the data, and exports a clean dataset.

---

##  Features
- Removes empty rows  
- Cleans column names  
- Sorts data by the first column  
- Saves a cleaned CSV file  
- Very beginner friendly
